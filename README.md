# Agent Memory

> 一个从“学习”走向“记住”的 Agent Memory 仓库。

## 项目目标

这个仓库现在关注一个更核心的问题：

**Agent 如何像人一样，在陌生任务中先依赖外部知识完成行动，再把重复执行过的步骤沉淀成自己的记忆，最终能够基于记忆独立推导下一步行动。**

我希望这个仓库讨论的，不只是“存储信息”，而是 **Memory 如何真正提升 Agent 的行动能力**。

## 一个从人类学习过程出发的记忆观

从人类学习做事的方式来看，记忆并不是一开始就存在的。

当一个人进入陌生环境，或者第一次被要求做一件从未做过的事情时，他通常不会直接知道下一步该怎么做。他需要先去学习：参考别人的指令、操作手册、案例，或者自己寻找相关资料，然后按顺序理解“先做什么，再做什么，再做什么”。

而当同一类事情做得足够多、足够熟练之后，这些步骤就不再依赖外部参考，而会逐渐变成他自己的记忆。此时，他可以直接根据当前情境和已有经验，推导出下一步该做什么。

基于这个观察，我目前把 Memory 理解为一个两层结构。

## 两层记忆理论

### 第一层：外部参考层

当人面对陌生任务时，首先依赖的是外部信息，而不是内部记忆。

这一层的典型特征是：

- 任务是新的，缺少稳定的内部经验
- 行动依赖外部指令、文档、案例或他人经验
- 关键能力不是“回忆”，而是“找到正确参考并组织成可执行步骤”
- 重点在于学习、检索、理解和按顺序执行

从这个角度看，第一层 Memory 的本质并不是“已经记住了什么”，而是：

**如何在需要行动时，快速找到可参考的知识，并把它转化成当前可执行的步骤。**

### 第二层：内化行动层

当一类任务被反复执行之后，原本依赖外部参考的步骤会逐渐被压缩、抽象并固化，成为可以直接驱动行动的内部记忆。

这一层的典型特征是：

- 不需要每次重新查资料
- 对步骤、顺序和判断条件已经形成稳定理解
- 能根据当前状态自然推导下一步动作
- 行动更多依赖经验化、程序化的内部结构

从这个角度看，第二层 Memory 的本质是：

**把做过、验证过、反复使用过的行动模式，沉淀成可以直接调用的内部能力。**

## 两层之间的关系

这两层并不是割裂的，而是一个连续的演化过程：

1. 先借助外部参考完成第一次行动
2. 在重复执行中积累经验
3. 从过程里提炼高频步骤和判断规则
4. 把这些规则压缩成稳定、可复用的记忆结构
5. 在下一次类似场景中，直接由记忆驱动行动

换句话说，Memory 不只是“保存过去的信息”，更重要的是：

**让下一次行动更少依赖外部搜索，更快进入有效执行。**

## 对 Agent 的启发

如果把这套理论放到 Agent 上，我认为一个好的 Agent Memory 系统至少应该支持下面几件事：

- 在陌生任务中，先找到可执行的外部参考
- 记录执行过程，而不只是记录最终答案
- 从重复成功的过程里提炼步骤、策略和判断模式
- 把可复用的经验沉淀成稳定 memory
- 在后续任务中优先调用已内化的记忆，只有在不确定时再回到外部检索

因此，我更关注的不是“Agent 能存多少上下文”，而是：

**Agent 能不能从一次次执行中逐渐形成自己的行动记忆。**

## 这个仓库会关注什么

接下来，这个仓库会逐步围绕 Agent Memory 展开，重点可能包括：

- Agent 如何从“查资料”过渡到“凭记忆行动”
- Memory 如何存储事实、经验、步骤、策略和偏好
- Memory 如何从执行轨迹中被写入和更新
- Memory 如何被检索、组合和触发
- Memory 如何帮助 Agent 判断下一步动作
- Memory 与 planning、workflow、tool use 之间的关系

## 当前核心判断

目前我对 Agent Memory 的一些核心判断是：

- 记忆不是单纯的信息存储，而是行动能力的压缩
- 好的 Memory 不只是能 recall，更要能支持 next action
- Agent 的成长不应只依赖更大的上下文窗口，还要依赖记忆的内化
- Memory 的价值不在于“记住多少”，而在于“减少多少重复学习”
